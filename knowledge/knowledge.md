# Knowledge router

| Folder | What goes there |
|---|---|
| `notes/` | Your own notes and thinking, one file per topic (`topic-name.md`) |
| `reading/` | Summaries of articles, books and videos, one file each, with the source link at the top. The Chrome clipper (`os/chrome-clipper/`) saves pages here with the page text; summarise on request |
| `references/` | Material you reuse: frameworks, checklists, guides (e.g. the ARMS guide) |
| `ideas/` | Raw ideas not yet acted on, one line each in `ideas.md` until they grow |

When something is saved here, add a line for it in the folder's `index.md` (create it on first use).
