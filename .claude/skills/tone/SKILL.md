# /tone

Database skill: the knowledge lives in `references/tone.md`. Keep this file short.

1. Read `references/tone.md` (principles first, then examples).
2. Draft in that voice. When you pitch options (titles, hooks, openers), give 10: 8 follow the references, 2 are wildcards (see `/wildcard`). Label the wildcards.
3. If Issam likes a wildcard, offer to add it to the examples in `references/tone.md`. Don't add it without a yes.
4. If `references/tone.md` still has no examples, ask Issam for 3 to 5 pieces of writing they're proud of, then fill it in and show the diff before saving.
